--------------------------------------------------------------------------------
INCIDENTES Y RESOLUCIONES
--------------------------------------------------------------------------------

1. NotNullViolation en migración 010

   Síntoma:
     column "category_code" of relation "dim_product" contains null values

   Causa:
     La migración autogenerada agregaba columnas NOT NULL a una tabla
     con 32 filas existentes. PostgreSQL no permite esto sin default.

   Solución:
     Migración en 3 pasos:
     1. Agregar columnas nullable.
     2. UPDATE con JOIN a staging.categories.
     3. ALTER COLUMN a NOT NULL.

2. Tipos de Recharts en Tooltip formatter

   Síntoma:
     Type '(value: string) => string' is not assignable to type 'Formatter'

   Causa:
     El tipo esperado es más amplio (ValueType | undefined).

   Solución:
     Usar typeof value === 'number' ? formatCurrency(value) : String(value ?? '').

3. Tipos de Recharts en Pie label

   Síntoma:
     Property 'channel' is missing in type 'PieLabelRenderProps'

   Causa:
     Recharts tipa el label con su propio tipo.

   Solución:
     Usar props.name ?? '' (name viene del nameKey).

4. Case sensitivity de Loading.tsx

   Síntoma:
     Already included file name 'Loading.tsx' differs from 'loading.tsx'

   Causa:
     Conflicto de case en Windows + TypeScript.

   Solución:
     Verificar que solo existe Loading.tsx (mayúscula) y limpiar cache
     de TypeScript si persiste.
